# MineVillagers — сборка

Здесь лежат опубликованные версии сборки MineVillagers (раздел **Releases**).
Играть удобнее через [VillagersLauncher](https://github.com/kokkas56/VillagersLauncher/releases/latest): он сам ставит Minecraft 1.21.1, NeoForge, Java и скачивает сборку.

Каждый выпуск `pack-N` содержит `manifest.json` со списком файлов и их контрольными суммами. Моды, которые есть на Modrinth, скачиваются оттуда.
